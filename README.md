# MMM-FIFAWorldCupDashboard ⚽🌍

Ein modernes FIFA World Cup Dashboard Modul für MagicMirror² mit:

- Live Gruppenphase (FIFA Tabellenlayout)
- Nächste Spiele mit Flaggen & Datum
- Live-Spielanzeige
- RSS News Feed Integration
- Knockout Turnierbaum (R32 → Finale)
- Automatischer Seitenwechsel (Dashboard / KO Phase)
- FIFA-inspiriertes Broadcast Design

## 🚀 Features

### 📊 Gruppenphase
- 12 Gruppen (A–L)
- Sortierung nach Platzierung
- Spalten: Spiele (S), Tordifferenz (GD), Punkte (P)
- Flaggen via flagcdn.com
- FIFA Layout Design

### 📅 Next Matches
- Kommende Spiele
- Flaggen für beide Teams
- Datum + Uhrzeit
- Saubere VS-Ausrichtung

### 🔴 Live Matches
- Live Score Anzeige
- Automatische Aktualisierung

### 📰 News
- RSS Feed Integration (z. B. kicker WM Feed)

### 🏆 Knockout Stage
- Turnierbaum Darstellung
- R32, R16, QF, SF, Final
- Automatische Freischaltung 2 Tage vor Start
